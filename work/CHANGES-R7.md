# R7 外部审查修复说明

日期：2026-11-22

## P1-1 作文 ID 与草稿同会话恢复

- `EssaySession` 现在同时保存 `documentId`、正文、结果、脏标记和在途请求 ID，作文页不再另维护一套可能错位的选中 ID。
- 挂载恢复时优先按会话中的作文 ID 找回摘要；有草稿时保留同一篇草稿，恢复结束后才持久化选择。正文失焦保存直接使用草稿所属的 `documentId`。
- 回归测试覆盖 A/B 两篇作文：打开 B、修改、切页返回后仍选中 B 且正文一致，A 不被覆盖，保存调用只指向 B。

## P1-2 历史版本默认只读

- 点击历次批改只进入独立只读预览，不再把旧正文装入可编辑会话，也不会触发失焦保存。
- 只有点击「恢复此版本」才把该快照放回编辑区；恢复本身保持干净状态，之后必须实际修改正文，失焦时才保存。
- 测试断言预览和恢复后的直接失焦均不写库，恢复后继续编辑才调用一次正文更新。

## P2-1 清空数据重置作文会话

- App 清空成功回调同步清空作文 ID、正文、结果、脏标记、在途请求和持久化选择。
- 作文页卸载会使旧请求序号失效；在途批改即使在清空后返回，也不能重新创建作文或追加批改记录。
- 测试覆盖“提交批改 → 清空全部数据 → 旧响应返回”，断言数据库仍为空，重新进入作文页也是空会话。

## P2-2 复习评分前重读日期

- 每次评分提交前重新调用本机日期来源；发现跨天时立即作废旧轮次、切换新日期并重载队列，不把昨天揭晓的卡评分写入昨天或新日期。
- 用户在新队列重新揭晓后再评分，事件使用提交时的新日期。
- fake-date 测试覆盖跨午夜第一次点击不记录、加载新日队列、重新揭晓后按新日记录的完整流程。

## P2-3 本轮复习状态统一与合并保序

- 删除独立的 `due` 状态；待复习数、历史忘记次数、AI 重点词输入和当前卡全部从同一份本轮 `queue` 派生。
- 刷新时保留现有顺序并更新卡片，移除失效项，再追加新到期项；旧 `[A]` 与新查询 `[A,B]` 合并为 `[A,B]`。
- 测试覆盖刷新保序追加，以及忘记 A 后队列变为 `[B,A]`、忘记次数立即更新、AI 收到同一份顺序和计数。

## P2-4 全文翻译限并发与切文停派

- 全文翻译改为 3 个工作者共享段落游标，最多同时发出 3 段，完成一段后才派发下一段。
- 每次取新段落前核对请求序号和文章 ID/版本；切换文章或发起新操作后，已发请求自然结束，但不再派发剩余段落，旧结果也不会显示。
- 可控延迟测试覆盖初始仅 3 请求、单段完成后补第 4 段，以及 6 段文章切文后请求数停留为 3。

## API Key 最小加固

- 新增 Tauri 命令 `save_model_api_key`、`get_model_api_key`。桌面端 Key 保存到应用数据目录下独立的 `model-api-key` 文件，不再写入 localStorage。
- Unix 文件权限设为 `0600`；Windows 使用当前用户应用数据目录及其 ACL。Rust 测试覆盖写入、覆盖、读取、清空和 Unix 权限。
- localStorage 的 `yuejian.modelService` 只保存供应商、Base URL、模型名和非敏感参数。旧版本遗留的明文 Key 在首次读取时迁移到文件并立即从 localStorage 移除。
- 精读和作文传输层支持异步读取桌面 Key；浏览器预览没有桌面文件通道，Key 仅保留在当前内存会话，刷新后需重新填写。
- 本轮是最小加固，不是系统凭据存储；macOS Keychain、Windows Credential Manager、Linux Secret Service 等完整系统凭据存储仍归阶段 5。

## 精简 1：统一打开文章流程

- 分区列表、资料库、收藏和复习回看统一经过 `openArticle`，集中处理编辑保存、文章与所属分区读取、段落定位、选择持久化和阅读页切换。
- 每次点击递增请求序号，只有最后一次点击可以应用结果或显示错误；迟到的旧文章响应不会覆盖新选择。
- 测试用可控延迟覆盖 B 先点击但后返回、C 后点击先返回，最终始终保持 C。

## 精简 2：作文摘要、按需历史与局部更新

- Rust 新增 `list_essay_summaries` 和 `get_essay_document` 命令；摘要包含当前正文和批改版数，但不包含历次正文与结果 JSON。
- 作文页启动只查询摘要，打开作文或首次展开某篇历史时才读取完整记录。
- 新建、重命名、正文保存、新增/删除批改和删除作文均更新对应本地条目，不再每次重载整篇列表。旧 `listEssayDocuments` 保留供数据层和测试使用。
- 前端测试断言整表摘要只查询一次、展开第二篇才读取第二篇历史、重命名不重载整表；Rust 测试断言摘要序列化不含历史载荷，详情可按需读取。
