# R4 修复说明

日期：2026-11-22

## 1. 生词本折叠显示

- `src/collection/CollectionPage.tsx`：生词默认收起，每条仅展示单词、词性和常见义首条；整条摘要均为可点击按钮，再次点击即可收起。
- 展开后保留原有完整信息：原句快照、规范化词形与原句、语境义、完整常见义、词形、来源文章与段落、复习信息，以及回看原文和移除操作。
- 每条生词独立维护展开状态，按钮的 `aria-expanded` 随状态切换，并通过 `aria-controls` 关联详情区。
- `src/styles.css`：仅新增生词摘要、详情和收藏页操作区样式；长难句列表结构及样式未改。

## 2. 生词本 CSV 导出

- 收藏页顶部新增「导出生词本」按钮，无生词时禁用。
- 使用前端 `Blob` 和临时下载链接导出，不调用后端。
- 文件为 UTF-8 CSV，开头包含 BOM（`EF BB BF`），使用 CRLF 换行，文件名格式为 `生词本-YYYY-MM-DD.csv`。
- 固定三列：`单词`、`词性`、`基本意思`。基本意思取常见义首条，不导出语境义、原句、规范化信息、来源、词形或其他完整解析内容。
- 每条生词对应一行数据，另有一行表头；长难句不参与导出。逗号、双引号等 CSV 特殊字符按标准转义。
