# 阅间 · 英语精读

阅间是一款 Windows 桌面英语学习工具。可以导入真题或粘贴文章，在阅读时查词、看句子解析，再把遇到的生词和长难句收藏起来复习。

## 下载安装

1. 打开 [最新版本下载页](https://github.com/tzq-tbw/yuejian-reader/releases/latest)，在 **Assets** 中下载名称以 `x64-setup.exe` 结尾的文件。
2. 双击安装包，按提示完成安装。安装包适用于 64 位 Windows（x64）。如果系统缺少 WebView2，安装程序会联网下载。
3. 安装完成后，在 Windows 开始菜单搜索「阅间」并打开。以后可以在应用的「设置 → 应用更新」中检查新版本。

## 主要功能

- **导入与整理**：只粘贴英文正文即可创建文章，标题和主题可选，或导入带文字层的真题 PDF。确认拆篇预览后导入，再用阅读分区整理文章。PDF 拆篇以四级真题版式为主。
- **精读**：划词查看语境义，翻译选区、段落或全文，解析长难句。可导入自己的词表并在正文中标色。
- **收藏与复习**：收藏生词和长难句，回看原句，按复习计划回顾生词。
- **作文批改**：提交英文作文获取 AI 批改，回看历史批改记录。

打开「资料库 → 粘贴新文章」即可添加正文。需要标色时，在「设置 → 词表管理」导入自己的词表。文章、收藏和复习记录存储在本机，导入、阅读和复习已有收藏可以离线使用。

## 启用 AI

查词、翻译、句法解析和作文批改需要配置可用的模型服务。

1. 打开「设置」里的「模型服务」，选择 **DeepSeek** 或 **通义千问**。
2. 从「模型」下拉菜单选择一个模型，填写供应商提供的 **API Key**，点击「保存模型配置」。服务地址会随供应商预填。如果你在用本机 Magpie，也可以选择「默认 Magpie 代理」并保持代理运行。
3. 回到文章，选中一个词并点击「查看词卡」，确认能看到释义。

调用 AI 时，相关文本会发送给你配置的模型服务。Windows 桌面版将 API Key 保存在当前用户的凭据管理器中。
